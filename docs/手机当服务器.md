# 把手机当成「此刻」的服务端

目的：数据不再只存在某个浏览器里。手机上跑一个小服务端，每次改动都存到手机上，并且自动留历史快照。别的设备（电脑、平板）也能连上来同步。

## 能做到什么

- **随时备份**：应用里每次改动，1.5 秒后存到服务端。覆盖旧数据前，服务端先给旧版本留一份快照（相邻两份至少隔 10 分钟）。2 天内的快照全留，2–90 天每天留最后一份，更早的删掉。
- **断电不坏**：写文件是“先写临时文件再改名”，写到一半断电，旧数据还在。
- **多设备同步**：两台设备都改了，会自动合并：两边新加的都留下，同一件以刚改的为准，删掉的不会再回来。
- **聊天用服务端的模型**：在服务端 `.env` 里填 `DEEPSEEK_API_KEY`，密钥只在手机上，浏览器里不用填。

## 只支持安卓

iPhone 不允许 App 在后台一直运行一个服务端，做不到。用 iPhone 的话，可以把服务端放在一台常开的电脑上（同样的步骤，见下面“在电脑上跑”）。

## 安卓：一步装好

1. 从 F-Droid（f-droid.org）安装 **Termux**、**Termux:Boot**、**Termux:API**，装完把 Termux:Boot 打开一次。
   三个必须来自同一个地方：插件和 Termux 的签名要一致。Google Play 版的 Termux 配不上 F-Droid 的插件，开机自启就装不上。已经装了 Play 版的，先卸载再装 F-Droid 版。
2. 打开 Termux，粘贴运行：
   ```
   curl -fsSL https://raw.githubusercontent.com/luminous-creator/cike/main/scripts/termux-setup.sh | bash
   ```
   代码还没合并到 main 时，在前面加上分支名：
   ```
   curl -fsSL https://raw.githubusercontent.com/luminous-creator/cike/ccr-2867821f-n0t9q5/scripts/termux-setup.sh | CIKE_BRANCH=ccr-2867821f-n0t9q5 bash
   ```
   它会安装 Node.js，下载并构建代码，生成口令，设置开机自启，最后启动服务端。第一次大约要 5–10 分钟。
3. 让它在后台活着。三星（One UI）杀后台很狠，这四步都要做：
   1. 设置 → 应用 → Termux → 电池 → **不受限制**
   2. 设置 → 电池 → 后台使用限制 → **永不休眠的应用** → 加入 Termux、Termux:Boot、Termux:API
   3. 设置 → 关于手机 → 软件信息 → 连点「版本号」7 次打开开发者选项；再到 设置 → 开发者选项 → 打开 **「停用子进程限制」**。Android 12 以后系统默认会杀掉 Termux 里的子进程（node 就是），不关掉会隔一阵就被杀
   4. 最近任务里长按 Termux 图标 → **锁定此应用**
4. 在手机浏览器打开 **http://localhost:3000** → 设置 → 同步与自动备份 → 勾选“同步到这台服务端”。再用浏览器菜单“添加到主屏幕”，以后从桌面图标打开。

> 一定要从 `http://localhost:3000` 打开。GitHub Pages 上的版本（https）连不了手机上的 http 服务端，浏览器会拦。localhost 在浏览器眼里是安全地址，装到桌面、通知都正常。

## 先检查一下手机

安装前或出问题时，在 Termux 里运行这个只读检查（不安装、不改任何东西），把输出发给 Claude：
```
curl -fsSL https://raw.githubusercontent.com/luminous-creator/cike/ccr-2867821f-n0t9q5/scripts/termux-check.sh | bash
```

## 把旧数据搬过来

在原来的应用（GitHub Pages 版）里：设置 → 导出备份。然后在 `http://localhost:3000` 的应用里：设置 → 导入备份 → 开启同步。

## 数据在哪

- 安装脚本把数据放在手机存储的 `Documents/cike-data/`，卸载 Termux 也不会丢：
  - `current.json`：最新数据
  - `backups/2026-11-01T20-30-00_r12.json`：快照（文件名是时间和版本号）
  - `server.log`：服务端日志
- 恢复某个时间点：把那份快照文件在应用里“导入备份”即可（快照就是备份文件的格式）。
- 设置页里可以直接“下载最新快照”。

## 电脑也想同步

电脑和手机连同一个 Wi-Fi，在电脑浏览器打开安装脚本最后显示的地址（`http://手机IP:3000`），设置里填口令（手机 `~/cike/.env` 里的 `SYNC_TOKEN`），再开启同步。

不在同一个网络时，可以在手机和电脑上都装 Tailscale，用 Tailscale 给的地址访问；用 `tailscale serve 3000` 还能拿到 https 地址，电脑上也能装成应用。

## 日常

- 改模型密钥：编辑 `~/cike/.env` 的 `DEEPSEEK_API_KEY`，不用重启。
- 更新到新版本：在 Termux 里再运行一次安装脚本（数据不受影响）。
- 手动启动：`~/cike/cike-start.sh &`；停止：`pkill -f "node dist/boot.js"; pkill -f cike-start`。

## 在电脑上跑

```
git clone https://github.com/luminous-creator/cike.git && cd cike
npm install && npm run build
cp .env.example .env    # 填 SYNC_TOKEN、CIKE_DATA_DIR、DEEPSEEK_API_KEY
npm start               # http://localhost:3000
```

## 局限

- 手机关机、Termux 被系统杀掉时，服务端不在。这期间应用照常可用，数据先存在浏览器里，服务端回来后再推上去。
- 两台设备同时改同一件事的同一项，以后推上去的那台为准。
- 聊天记录和提示词只存在各自的设备上，不同步。
